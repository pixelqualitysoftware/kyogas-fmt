# kyogas-fmt

A CLI formatting tool for [Kyogas](https://github.com/pixelqualitysoftware/kyogas).

## Installing

Install it by using `go install`.
```bash
go install github.com/pixelqualitysoftware/kyogas-fmt@latest
```

## Usage

```
Usage:
  kyogas-fmt [command]

Available Commands:
  completion  Generate the autocompletion script for the specified shell
  format      Format a kyogas file
  help        Help about any command

Flags:
  -h, --help   help for kyogas-fmt

Use "kyogas-fmt [command] --help" for more information about a command.
```
